# 📄 PDF RAG Assistant (LangChain + Ollama)

Простой проект для работы с PDF-документами с использованием Retrieval-Augmented Generation (RAG) и локальных LLM через Ollama.

---

## 🚀 Возможности

- 📄 Извлечение текста из PDF
- ✂️ Разбиение текста на чанки
- 🧠 Генерация эмбеддингов через Ollama
- 🔎 Хранение векторов в FAISS
- 🤖 Ответы на вопросы по документу
- 🔒 Полностью локальная работа (без API)

---

## 🏗️ Технологии

- Python
- LangChain
- FAISS (векторное хранилище)
- Ollama (LLM + embeddings)
- PyPDF

---

## ⚠️ Требования к Python

Рекомендуемая версия Python:

```text
Python 3.10 – 3.12
```

Проект протестирован на Python 3.12.

Использование Python 3.13 и новее не рекомендуется, так как некоторые зависимости (FAISS, LangChain, Ollama и связанные библиотеки) могут работать нестабильно или вызывать ошибки на отдельных платформах.

## 📦 Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/PSH-3/pdf-rag.git
cd pdf-rag
```

### 2. Создать виртуальное окружение

```bash
python -m venv venv
source venv/bin/activate  # Mac/Linux
venv\Scripts\activate     # Windows
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

---

## 🧠 Установка Ollama

Скачайте Ollama с официального сайта:

👉 https://ollama.com

После установки запустите сервер:

```bash
ollama serve
```

---

## 📥 Загрузка моделей

Проект использует следующие модели:

### 🔹 LLM (для генерации ответов)

```bash
ollama pull qwen2.5:3b
```

### 🔹 Модель эмбеддингов

```bash
ollama pull nomic-embed-text
```

При необходимости модели можно изменить в `.env`.

---

## ⚙️ Конфигурация

Создайте файл `.env` в корне проекта:

```env
PDF_PATH="./data/example.pdf"

CHUNK_SIZE=1000
CHUNK_OVERLAP=200
CHUNK_COUNT=4

EMBEDDING_TYPE="OLLAMA"
EMBEDDING_MODEL="nomic-embed-text"

LLM_MODEL="qwen2.5:3b"
LLM_URL="http://localhost:11434"
```

## ⚡ Как это работает

1. PDF → извлечение текста  
2. Очистка текста  
3. Разбиение на чанки  
4. Генерация эмбеддингов (Ollama)  
5. Сохранение в FAISS  
6. Поиск релевантных чанков  
7. Генерация ответа LLM на основе контекста
